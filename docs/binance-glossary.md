# คำศัพท์เฉพาะ Binance (ภาษาไทย)

เอกสารนี้อธิบายคำศัพท์เฉพาะของ Binance และการตั้งค่า 1H ในระบบของเรา

---

## 1. "1H" คืออะไร

**1H = 1 Hour = 1 ชั่วโมง** เป็นหนึ่งใน "timeframe" (กรอบเวลา) ของกราฟและข้อมูลตลาด

| ตัวย่อ | ความหมาย |
| --- | --- |
| 1m, 5m, 15m, 30m | นาที (1, 5, 15, 30 นาที) |
| **1H**, 2H, 4H | ชั่วโมง (1, 2, 4 ชั่วโมง) |
| 1D, 3D | วัน (1 วัน, 3 วัน) |
| 1W | สัปดาห์ |
| 1M | เดือน |

**สำคัญ**: Binance ใช้เวลา **UTC** (เวลาสากล) ไม่ใช่เวลาไทย (GMT+7) ดังนั้น 05:05 UTC ใน workflow คือ 12:05 น. เวลาไทย

## 2. "1H .data" ในระบบของเรา

ระบบ `binance-1h-data.yml` รันอัตโนมัติทุก ๆ **1 ชั่วโมง** (ครั้งแรก ณ นาทีที่ 5 ของทุกชั่วโมง UTC) ดึงข้อมูล Binance แบบ Read-Only ทั้งหมด แล้วบันทึกเป็นไฟล์ `data/binance-1h.data` บน GitHub — นั่นคือเหตุผลที่ชื่อไฟล์และ workflow มีคำว่า "1h" อยู่

## 3. คำศัพท์เฉพาะอื่น ๆ ของ Binance

| ศัพท์ | คำอธิบาย |
| --- | --- |
| Spot | ตลาดซื้อ-ขายสินทรัพย์จริง (ได้เหรียญมาถือเลย) |
| Futures (USDT-M) | สัญญาซื้อขายล่วงหน้าใช้ USDT เป็นหลักค้ำประกัน — มีเลเวอเรจ |
| Funding Rate | อัตราค่าธรรมเนียมที่ฝั่ง long จ่ายให้ฝั่ง short (หรือกลับกัน) อัปเดตทุก 8 ชม. — ค่ายิงว่าฝั่ง long แน่นเกิน |
| Margin | เทรดด้วยเงินกู้ยืม (ยืมเหรียญมาเทรด/ยืมเหรียญมาขายก่อน) |
| Leverage | อัตราส่วนยืมเงิน เช่น 5x, 10x |
| Maker / Taker | Maker = ฝั่งวางออร์เดอร์รอ (คอมมิชั่นถูกกว่า), Taker = ฝั่งกินออร์เดอร์ทันที |
| Order Book (Depth) | รายการออร์เดอร์ซื้อ/ขายทั้งหมดที่รออยู่ |
| K-line / OHLCV | กราฟแท่งเทียน: Open, High, Low, Close, Volume |
| Ticker | ราคาปัจจุบัน + การเปลี่ยนแปลง 24 ชม. ของหนึ่งสัญลักษณ์ |
| API Key / Secret Key | คู่รหัสเข้าถึง API — Key เป็นชื่อ, Secret เป็นคีย์ลับสำหรับลงนาม HMAC |
| HMAC-SHA256 | เทคนิคสร้างลายเซ็นดิจิทัลสำหรับคำขอร้องแบบ private ของ Binance |
| Rate Limit | ขีดจำกัดจำนวนคำขอร้องต่อนาที (weight) |
| UID | เลขประจำตัวบัญชี Binance (ของคุณคือ 115213344) |
| BNB Alpha | ดัชนีแสดงโมเมนตัมของ BNB เปรียบเทียบ 24 ชม. พร้อมจำนวนคู่ BNB ในระบบ |
| Smart Money Opinion | มุมมองตลาดอัตโนมัติ: bullish (ขาขึ้น) / neutral (ทรงตัว) / bearish (ขาลง) |
| Read-Only | โหมดอ่านข้อมูลอย่างเดียว — ไม่มีการสั่งซื้อ/ขาย/ถอนเงินใด ๆ |
| Tokenized Stock | โทเคนที่แสดงหุ้นจริง (เช่น TSLA, AAPL) เทรดบน Binance |

## 4. ความหมายของสัญลักษณ์ที่ระบบติดตาม

| สัญลักษณ์ | ความหมาย |
| --- | --- |
| BTCUSDT | ราคา Bitcoin เทียบ USDT |
| ETHUSDT | ราคา Ethereum เทียบ USDT |
| BNBUSDT | ราคา BNB (เหรียญประจำตัว Binance) เทียบ USDT |
| SOLUSDT | ราคา Solana เทียบ USDT |

## 5. การใช้ใน binance-cli

```bash
binance-cli spot ticker --symbol BTCUSDT        # ราคา spot ปัจจุบัน
binance-cli spot klines --symbol BTCUSDT --interval 1h   # แท่งเทียน 1H
binance-cli futures-usds exchange-information   # ข้อมูลฟิวเจอร์ส
```
